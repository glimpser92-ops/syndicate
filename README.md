# NEON SYNDICATE

방장을 제외한 4~20인 협력·배신 라운드제 웹 게임. 학생들은 해커가 되어 7라운드 동안 동맹을 맺고, 채굴하고, 배신하며 크레딧을 모읍니다. **최종 상위 20%만 생존합니다.**

## 실행

```bash
npm install
node server.js
```

브라우저에서 `http://localhost:3000` 접속 → 방장 모드로 방 개설 → 학생 링크 또는 4자리 코드 공유 (같은 네트워크의 다른 기기는 `http://<호스트IP>:3000`).
방장은 플레이어로 참가하지 않고 진행 상황과 규칙 설정만 관리합니다. 인원이 모자라면 봇으로 채울 수 있습니다.

## 온라인 배포

이 게임은 실시간 방 입장과 게임 진행에 WebSocket 서버가 필요합니다. 그래서 GitHub Pages처럼 정적 HTML만 올리는 방식으로는 멀티플레이가 동작하지 않습니다. GitHub에는 코드를 올리고, Render 같은 Node.js 웹 서비스가 GitHub 저장소를 읽어 실행하게 배포하세요.

### GitHub에 올리기

```bash
git init
git add .
git commit -m "Prepare multiplayer classroom deployment"
git branch -M main
git remote add origin https://github.com/<내계정>/<저장소>.git
git push -u origin main
```

### Render에 배포하기

1. Render에서 `New` → `Web Service`를 선택합니다.
2. GitHub 저장소 `neon-syndicate`를 연결합니다.
3. 설정은 아래처럼 둡니다.
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Health Check Path: `/healthz`
4. 배포가 끝나면 Render가 만들어 준 `https://...onrender.com` 주소로 접속합니다.

`render.yaml`이 포함되어 있어서 Render Blueprint로도 같은 설정을 자동 인식할 수 있습니다.

### 수업에서 쓰는 방법

1. 방장/교사가 배포 주소에 접속합니다.
2. 이름을 입력하고 `새 신디케이트 개설`을 누릅니다.
3. 로비에 표시되는 `학생 접속 링크`를 복사하거나 QR/코드를 보여줍니다.
4. 학생은 링크를 열면 방 코드가 자동 입력됩니다. 이름만 입력하고 `초대 방 접속`을 누르면 됩니다.
5. 최소 4명이 모이면 방장이 `침투 개시`를 누릅니다. 부족하면 봇으로 채울 수 있습니다.
6. 게임 중에도 방장 화면에 재접속 코드/QR과 전체 진행 상황이 표시됩니다.
7. 방장은 게임 중에도 동맹 한도, 라운드 수, 생존 비율, 채굴/해킹/배신 수치, 신호/행동 시간을 조절할 수 있습니다.

## 규칙 요약

매 라운드: **이벤트 공개 → 신호 교환(22초) → 행동 결정(18초) → 동시 정산**

| 행동 | 효과 |
|---|---|
| ⛏ 채굴 | +30. 동맹이 함께 채굴하면 동맹 1명당 +15 |
| 🛡 방화벽 | +10. 나를 해킹한 해커에게서 30 반격 탈취 |
| ⚡ 해킹 | 채굴자에게서 40 탈취. 대상이 방화벽이면 역으로 30을 뺏김 |

- **동맹**: 신호 페이즈에 제안/수락 (기본 최대 3개, 방장이 조절 가능). 합동 채굴 보너스의 원천.
- **배신**: 동맹을 해킹하면 60 탈취 — 단, 🔻 배신자 낙인이 찍혀 다음 라운드에 모두에게 1.5배로 털립니다.
- **현상금 👑**: 매 라운드 1위는 공개 타깃. 해킹 성공 시 보너스 → 선두 견제 자동 발생.
- **이벤트**: 데이터 러시(채굴 2배) / 제로데이(해킹 2배) / 보안 패치(방화벽 강화) / 현상금 폭등 / 동맹 배당 / 대숙청(배신 2배·낙인 없음) / EMP 폭풍(전 수익 절반) — 매 라운드 최적 전략이 뒤바뀝니다.
- **소통**: 자유 채팅 없음. 동맹 제안 · ⚠️ 경고 · 이모지 신호만으로 의중을 읽고 속이세요.
